THE BACKROOMS — BETA FECHADA (Lobby 0: "O Amarelo Infinito")
=============================================================

FORMA CERTA DE JOGAR (Windows):
  1. Extrai a pasta inteira para onde quiseres (ex.: Documentos\Backrooms)
  2. Duplo-clique em JOGAR.bat   <-- É ISTO QUE ABRES
  3. Abre-se o browser sozinho em http://127.0.0.1:8321/backrooms.html
  4. Clica no ecrã para prender o rato. Esc liberta-o.

SE NESTA PASTA FALTAR O JOGAR.bat:
  - o download ficou incompleto (ou o antivírus apagou o .bat);
  - descarrega outra vez: https://github.com/edmundo738/Nsambo/releases/tag/backrooms-v0.1.0-beta
  - extrai para uma pasta NOVA e verifica que lá estão JOGAR.bat e server.ps1;
  - alternativa: usa o instalador NSAMBO-THE-BACKROOMS-0.1.0-beta-Windows-setup.exe
    (duplo-clique, instala, abre pelo atalho «NSAMBO-BACKROOMS»).

NÃO precisas de instalar nada (npm/node/vite) — o JOGAR.bat faz tudo.
(O endereço localhost:5173 é só para quem está a desenvolver o jogo;
 para jogar a beta usa o JOGAR.bat ou o instalador.)

NÃO abras backrooms.html diretamente com duplo-clique:
  - o Chrome/Edge bloqueiam o jogo por segurança (módulos ES em file://);
  - o JOGAR.bat resolve isso com um servidor local só teu, sem internet.

SE O WINDOWS SMARTSCREEN AVISAR:
  - "Mais informações" -> "Executar assim mesmo". É um script local assinado
    por ninguém (beta), mas só serve os ficheiros desta pasta.

CONTROLOS
  WASD andar · SHIFT correr · ESPAÇO saltar · E interagir
  LMB (botão esquerdo) facada — ataca na direção da mira
  F lanterna · M mini-mapa · Esc libertar rato

OBJETIVO
  Encontra a chave. Abre a porta SAÍDA. Sobrevive ao amarelo.
  Ele ouve o ferro — o golpe da faca atrai o stalker. Cuida da VIDA:
  quando a barra estiver curta, as bordas pulsam e o coração dispara.
  O medkit devolve vida. Três facadas no peito derrubam o stalker para sempre.

A ENCONTRAR BUGS?
  Abre uma Issue: https://github.com/edmundo738/Nsambo/issues
  Manda: o que aconteceu, a seed, o que estavas a fazer, um print.
  Obrigado por testar — é a primeira beta e cada bug report conta.

MULTIJOGADOR (LAN) — 1v1 na tua rede Wi-Fi/cabo
  O HOST (quem cria a sala) precisa de Node.js (https://nodejs.org, LTS):
    1. Duplo-clique em LAN.bat  (ou: node relay.cjs)
    2. No jogo: MULTIJOGADOR (LAN) -> CRIAR — SOU O CAÇADOR (ou FUGIDOR)
  O CONVIDADO (sem Node):
    1. Abre o jogo na mesma rede
    2. MULTIJOGADOR (LAN) -> PROCURAR PARTIDAS -> ENTRAR na sala listada
    3. Ou escreve o IP do host (192.168.x.x:8322) em ENTRAR
  Caçador vence esvaziando a vida (LMB, 2.9 m). Fugidor vence abrindo
  a porta SAÍDA com a chave. Seed partilhado, papéis opostos.
  Bluetooth: não suportado (Web Bluetooth não faz jogos ponto-a-ponto).
